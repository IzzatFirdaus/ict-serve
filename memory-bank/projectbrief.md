# Project Brief

## Project Goals

- Deliver a robust, accessible, and maintainable digital service platform for MOTAC, following government digital principles
- Ensure all features and UIs are compliant with WCAG AA and government standards
- Enable rapid onboarding and contribution for new developers

## Stakeholders

- Ministry of Tourism, Arts and Culture (MOTAC)
- Internal ICT team and system administrators
- Malaysian citizens and service users

## High-Level Requirements

- Use Laravel 12, Filament v4, Livewire 3, and TailwindCSS 4 as core stack
- Implement modular, maintainable architecture with clear documentation
- Provide feature-branch workflow, CI/CD, and automated testing
- Maintain a living memory bank for project context and onboarding
